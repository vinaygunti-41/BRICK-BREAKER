## 🕹️ About The Project

**Brick Breaker** is a classic arcade-style game built using **HTML, CSS, and JavaScript**. Control the paddle, bounce the ball, destroy all the bricks, and achieve the highest score.

Designed with a **Neon Red Gaming UI** featuring glowing borders, dark backgrounds, clean controls, and lightweight gameplay.

> **Simple. Fast. Addictive.**

---

## ✨ Features

| Feature              | Description                               |
| -------------------- | ----------------------------------------- |
| 🎮 Classic Gameplay  | Bounce the ball and destroy all bricks.   |
| ❤️ Neon Red Theme    | Premium dark UI with glowing red accents. |
| 🧱 Multiple Bricks   | Break rows of colorful bricks.            |
| 🏓 Paddle Controls   | Smooth left and right movement.           |
| ⚽ Ball Physics       | Collision with walls, paddle, and bricks. |
| 📊 Live Score        | Score increases as bricks are destroyed.  |
| 💖 Lives Counter     | Multiple chances before Game Over.        |
| 📱 Responsive Canvas | Works on desktop and mobile browsers.     |
